# Checklist depot original

Avant une contribution, verifier que le profil GitHub n affiche pas « Forked from ». Relever le proprietaire, la visibilite, la branche par defaut, la licence et la possibilite de modifier le depot. Conserver le lien vers la page de commits et la date du controle.

Cette checklist evite de confondre un fork documentaire avec une contribution reconnue par Guild.
