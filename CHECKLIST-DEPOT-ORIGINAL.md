# Checklist dépôt original

Avant une contribution, vérifier que le profil GitHub n’affiche pas « Forked from ». Relever le propriétaire, la visibilité, la branche par défaut, la licence et la possibilité de modifier le dépôt. Conserver le lien vers la page de commits et la date du contrôle.

Cette checklist évite de confondre un fork documentaire avec une contribution reconnue par Guild.
