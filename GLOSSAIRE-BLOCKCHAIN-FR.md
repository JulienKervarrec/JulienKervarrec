# Glossaire blockchain français

- **Account abstraction** : modèle séparant intention utilisateur, validation et exécution d’une opération.
- **AIR** : représentation algébrique d’une trace d’exécution utilisée dans des preuves STARK.
- **Finalité** : degré de certitude qu’un état ne sera plus réorganisé.
- **Paymaster** : composant pouvant sponsoriser des frais selon des règles définies.
- **Préimage** : donnée engagée par un hash et nécessaire pour retrouver la valeur engagée.
- **Witness** : valeurs privées complétant les entrées publiques d’une relation prouvée.
- **FRI** : protocole de vérification de faible degré utilisé dans plusieurs systèmes STARK.
- **Nonce** : valeur ordonnant une action et empêchant sa réutilisation.
- **TEE** : environnement d’exécution isolé reposant sur une attestation matérielle.

Les termes doivent toujours être interprétés dans le protocole et le modèle de confiance étudiés.
